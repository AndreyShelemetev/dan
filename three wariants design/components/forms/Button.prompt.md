Кнопка-пилюля; primary — не больше одной на экран, текст — глагол («Создать заявку», «Оплатить»).

```jsx
<Button variant="primary" size="lg" onClick={submit}>Создать заявку</Button>
<Button variant="secondary">Заказать осмотр</Button>
```

danger — только для необратимых действий (отмена заказа); терракота, не алый.
