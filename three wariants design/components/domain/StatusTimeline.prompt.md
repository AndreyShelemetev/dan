Таймлайн публичных статусов заказа (FR-CUS-012): у каждого шага — понятный текст и следующий шаг.

```jsx
<StatusTimeline steps={[
  { label: "Смета принята", note: "Версия 2 · 12 640 ₽", state: "done" },
  { label: "Работа выполняется", note: "Визит: 19–21 августа", state: "current" },
  { label: "Проверяем качество", state: "upcoming" },
]} />
```

`orientation="horizontal"` — компактная полоса прогресса на публичных страницах.
