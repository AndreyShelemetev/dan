# Память рядом — дизайн-система

Дизайн-система MVP сервиса «Память рядом» — управляемого сервиса дистанционного ухода за захоронениями в Санкт-Петербурге. Клиент заказывает уход, оператор назначает проверенного исполнителя, проверяет отчёт «до/после» и отвечает за результат.

Источник требований: `uploads/TZ_MVP_Pamyat_ryadom_Claude_Code.pdf` (ТЗ v1.0, 21.08.2026). Дизайн-принципы взяты из раздела 07: спокойный, деликатный визуальный язык; без агрессивных таймеров, красных «срочно» и манипуляции чувством вины; на каждом шаге видны статус, следующий шаг и срок.

Поверхности продукта:
1. **Публичный сайт** — главная, каталог услуг, доверие, FAQ, заявка (RU/EN).
2. **Кабинет клиента** — захоронения, заказы, сметы, оплата, отчёты, обращения.
3. **Мобильный интерфейс исполнителя** — назначения, чек-лист, фото, офлайн-очередь.
4. **Backoffice** — диспетчер, QA, финансы, поддержка, справочники.

Выбранное направление: «Тихий сад» — слоновая кость, приглушённый зелёный, серифный акцент (Spectral) поверх спокойного гротеска (Manrope).

## CONTENT FUNDAMENTALS

- Тон: **деловой, сдержанный, на «вы»**. Без пафоса, без эвфемизмов, без манипуляции чувствами. Пишем «уход за захоронением», «место памяти» — не «услуги для усопших».
- Обещаем только проверяемое: «фотоотчёт по обязательным ракурсам», «контроль качества по каждому заказу». Запрещены «100% защита» и подобные неподтверждённые обещания (FR-PUB-003).
- Статусы — понятным языком с ясным следующим шагом: «Смета готова → Посмотреть и подтвердить», «Проверяем качество → Ожидать». Полная карта публичных статусов — в ТЗ, раздел 04.
- Цена всегда рядом с составом и ограничениями; «от» не маскирует обязательный осмотр.
- Ошибки объясняют, что произошло и что делать; без внутренних кодов.
- Заголовки — с большой буквы, без Title Case. Эмоджи не используются.
- RU/EN; деньги — «12 640 ₽» (неразрывный пробел в разрядах), даты — «19–21 августа».

## VISUAL FOUNDATIONS

- **Цвет**: фон страницы — слоновая кость `--paper #F5F3EE`; карточки `--surface #FBFAF6`; текст — тёплый графит `--ink-1 #2B2F2B`. Один акцент — приглушённый зелёный `--accent #4A6151`. Семантика намеренно приглушена: опасность — терракота `#8C4A3F`, не алый; критичные действия не полагаются только на цвет.
- **Типографика**: Spectral (серифный, weight 300–600) — только заголовки h1–h3, крупные цифры и названия пакетов; Manrope — всё остальное (UI, body, кнопки). Надзаголовки: 12px, uppercase, letter-spacing 0.18em, цвет `--ink-3`, часто с разделителем «·».
- **Фон**: сплошные заливки, без градиентов, паттернов и текстур. Никаких фоновых изображений в UI; фотографии живут только в контенте (отчёты «до/после»).
- **Карточки**: фон `--surface`, рамка 1px `--border`, радиус 4px, тень `--shadow-card` (едва заметная). Модальные — `--surface-raised`, `--shadow-modal`.
- **Кнопки**: полностью скруглённые (pill, 999px). Primary — заливка `--accent`; secondary — прозрачная с рамкой `--border-strong`. Радиусы: pill только для кнопок и бейджей, 4px для всего остального.
- **Анимация**: сдержанная — 160ms, ease-out; только opacity и цвет. Без bounce, без крупных движений; уважать reduced motion.
- **Hover**: кнопки темнеют (`--accent-hover`); карточки-ссылки — рамка `--border-strong`; ссылки — `--accent-deep`. Press: без масштабирования, только цвет глубже (`--accent-deep`).
- **Разделители**: тонкие линии 1px `--border` — основной приём структуры (вместо теней и цветовых блоков).
- **Прозрачность/blur**: не используются, кроме подложки модальных окон (rgba(43,47,43,0.4)).
- **Фотографии**: только реальные фото отчётов; тёплая нейтральная обработка не требуется, кадры показываются как есть. Плейсхолдеры — заливка `#E9E1D4`-класса с подписью ракурса.
- **Layout**: контейнер 1080–1120px; воздух крупный (секции 56–88px). Мобильные хит-таргеты ≥44px.

## ICONOGRAPHY

- Логотипа нет — словесный знак «Память рядом» набирается Spectral 500. **Не рисовать логотип.**
- Иконки: [Lucide](https://lucide.dev) c CDN (`https://unpkg.com/lucide-static/icons/<name>.svg` или lucide-react), stroke 1.5px, цвет `currentColor`, размер 16–20px. Тонкий штрих соответствует сдержанному тону. Не использовать эмоджи и юникод-символы как иконки (кроме типографских «·», «→» в тексте).
- Иконки — вспомогательные: статус всегда дублируется текстом.
